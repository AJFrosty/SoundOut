# docs — the record

| file | what it is |
|---|---|
| `RADIO.md` | Step by step, with the hardware in front of you: what to buy, what to switch off in the radio's menus, how to set levels, and the five things that will actually go wrong. |
| `comparison.svg` | How old the base's information is over three days, against a runner, a phone network, nothing at all, and a perfect link. Generated by `python -m experiments.comparison`. |
| `logo.svg` | The SoundOut mark — a signal spreading over a roofline. Also inlined in `field.html` so the page has no external requests. |

## Regenerating the chart

```bash
python -m experiments.comparison
```

It writes `comparison.svg` and prints the tables that go with it. Every assumption is a
named constant at the top of `experiments/comparison.py` — how often a runner sets out, how
fast one travels, when the phone network comes back — so anyone who disagrees with one can
change a line and re-run the whole comparison.
