# docs — the record

| file | what it is |
|---|---|
| `RADIO.md` | Step by step, with the hardware in front of you: what to buy, what to switch off in the radio's menus, how to set levels, and the five things that will actually go wrong. |
| `JOURNAL.md` | The design journal. Ten weekends of what was tried, what it measured, and what turned out to be wrong. The longest and most useful document in the project. |
| `comparison.svg` | How old the base's information is over three days, against a runner, a phone network, nothing at all, and a perfect link. Generated by `python -m experiments.comparison`. |
| `logo.svg` | The SoundOut mark — a signal spreading over a roofline. Also inlined in `field.html` so the page has no external requests. |

## The journal

`JOURNAL.md` is organised as one section per weekend, each with the goal it started from,
the measurements it produced, and the things that went wrong. It is worth reading in order
if you want to know *why* rather than *what*.

| weekend | what it settled |
|---|---|
| 1 | Four tones and a Goertzel detector, and why not an FFT |
| 2 | A chirp preamble and matched filter, after the energy threshold failed at 5 dB |
| 3 | The 12-byte schema and the two tiers of authentication; then real hardware |
| 4 | The convergent store, and the picture as a fold over a grow-only set |
| 5 | Reed–Solomon, and two bugs in Berlekamp–Massey that made it correct nothing |
| 6 | Long-range modes, and discovering the fixed chirp had become the ceiling |
| 7 | The radio hop and the VOX wake-up tone; a feature built, measured and deleted |
| 8 | Store and forward — the difference between a modem and a network |
| 9 | What it is worth against the alternatives, including where it loses |
| 10 | Signed orders outwards, and a digest that tells a shelter its report arrived |

## Regenerating the chart

```bash
python -m experiments.comparison
```

It writes `comparison.svg` and prints the tables that go with it. Every assumption is a
named constant at the top of `experiments/comparison.py` — how often a runner sets out, how
fast one travels, when the phone network comes back — so anyone who disagrees with one can
change a line and re-run the whole comparison.
